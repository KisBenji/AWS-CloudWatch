# AWS-CloudWatch

Amazon CloudWatch

Az Amazon CloudWatch segítségével könnyen nyomon követhetjük, hogyan működnek az alkalmazásaink és a felhőben futó erőforrásaink.

Segítségével láthatjuk a teljesítményadatokat, megnézhetjük a naplókat, és riasztásokat állíthatunk be, ha valami nem a megszokott módon működik.

Főbb funkciói amiknek a működését fogjuk részletesebben megnézni: 

📊 Metrics: teljesítményadatok és erőforrás-használat követése.

📝 Logs: naplók gyűjtése és elemzése a hibák felderítéséhez.

🚨 Alarms: automatikus riasztások beállítása.

📈 Dashboards: az adatok és a szerver állapotának megjelenítése.
